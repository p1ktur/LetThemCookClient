This is the main branch for developing LetThemCook.

This pet project is developed as my Diploma project for my University. The application features almost all my knowledge in Android, Kotlin and Jetpack Compose.
Features I have used in this project are: Jetpack Compose, Coroutines, Ktor (REST API), Koin (DI), Exoplayer, Navigation, Animations, RoomDB (SQL), SharedPreferences.

Application represents the online platform for sharing recipes. It offers next possibilities: Creating Accounts, Changing Password, Customizing Profile, Changing app language, Changing App theme, Creating Recipes, Editing them, Building interesting cooking with blocks in special editor, Publishing recipes, Reviewing recipes, Reacting on Recipes, Following other users, Searching recipes while filering or sorting them, Searching users

Server for this client is written in Kotlin with Ktor. For Database it is using PostgreSQL which was accesses with Kotlin Exposed.
You can find the code here: https://github.com/p1ktur/LetThemCookServer/tree/master

P.S. If you closely inspect this project you may notice features which can be improved or optimized but weren't. That is because I was limited in my schedule and could not afford to optimize everything ideally, since I also did write code for everything myself and for free, so please consider this fact.
